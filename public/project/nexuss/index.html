🦆 NexusS — Merging Study Sessions

🚀 Built in 34 Hours
🏆 BIG Hackathon Project
✨ Theme: Merger

“Merge your study. Meet your people.”

🌟 Project Overview

NexusS was built in under 34 hours for the BIG Hackathon , hosted by the Computer Science Club (CS Club), University of Adelaide and the UniSA Programming Community (UPC), University of South Australia .

The idea is simple:

NexusS helps students merge independent study sessions by connecting them with others nearby.

✨ With NexusS, students can:

  • 🔎 Discover nearby study sessions based on courses or interests
  • 📍 Drop by and join sessions happening around them
  • 📝 Host a session by marking their location and inviting others

NexusS helps university students find study buddies — and maybe even new friends.

🗺️ Navigating the UI

  1. 📍 See your location (red marker) and nearby study sessions (ducks 🦆).
  2. 🦆 Click a duck to view:
    • Description
    • Capacity
    • Time
    • Location
    • Image
    • Tags
  3. ➕ Create your own study session using the form.
  4. 💡 Receive helpful suggestions for nearby sessions.
  5. ❓ Check the FAQ if you ever feel lost.

👉 Try it here: https://nexuss2025.vercel.app/

🛠️ Tech Stack

🎨 Frontend

  • Next.js
  • TypeScript
  • Shadcn UI
  • Tailwind CSS

🗄️ Backend

  • MongoDB
  • Supabase (image storage)
  • Vercel (deployment)

🧰 Other Tools

  • MapLibre (interactive maps)
  • MapTiler Cloud (map styling & data source)
  • Zod (form validation)

🚀 Key Features

  • 📚 Browse nearby study sessions by course or interest
  • 📍 Share your current study location to invite others
  • 📱 Fully responsive and mobile-friendly

💻 Installation 

npm install
npm run dev

Then open:

http://localhost:3000
